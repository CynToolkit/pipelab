## Intent

A premium, motion-first product commercial for indie game developers and small
studios. Show the release work after a game is finished gathering into a single
Pipelab Release workflow. The UI is a designed, simplified motion surface based
on the current product structure, not a screenshot or generic node canvas.

## Assets

- Current Pipelab application icon — end card and product reveal.
- Official Construct 3, Steam, itch.io, and Poki marks — animated source and
  destination identities.

## Customizations

- Animate directed paths through the Release workspace: Construct web output to
  Poki; Construct through Electron · Windows x64 to Steam and itch.io.
- Use moving pulses and morphing interface elements to make the source-to-
  destination direction legible without depicting a graph editor.
- Use kinetic typography, restrained electronic music, and designed UI sound
  effects. No voiceover.

## Notes

- Preserve current product terms and behavior: New release; Details, Source,
  Destinations, Review; Configuration, Builds, Artifacts, Runs; Ready to ship;
  Ship; Build profiles; Deliveries.
- A Construct source is a web application artifact. Electron can produce a
  Windows x64 desktop artifact for Steam and itch.io; Poki accepts the web
  artifact. Show these as distinct routes in the same workflow.
- Do not show a Release workflow node canvas, fake command spam, stock footage,
  scheduled shipping, automatic continuous deployment, or retries.
- Aim for 25 seconds, landscape 16:9, with a dark graphite field and Pipelab
  blue accent. Keep the final brand line “Ship games, not release scripts.”

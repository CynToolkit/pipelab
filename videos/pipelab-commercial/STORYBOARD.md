# Product launch storyboard

A single continuous 45-second product showcase. This is one persistent composition, not separate screens.

| Time | Story beat | Hold / read |
| --- | --- | --- |
| 0–3s | Your game is ready — Your Game / Web project / Construct 3 | Establish the project |
| 3–7s | Web build, Desktop build, Steam, itch.io, Poki reveal sequentially | Different destinations need different outputs |
| 7–12s | Pipelab frame/header organizes the existing elements | One release. Multiple destinations. |
| 12–17s | Select Steam, itch.io, and Poki | Choose where you want to ship |
| 17–25s | Web artifact routes to Poki and resolves to Electron Windows x64 for Steam/itch.io | Hold the complete route map |
| 25–29s | Same objects regroup into a 3×2 execution view; Ship | Ready state before click |
| 29–37s | Six sequential source/build/delivery steps | One traveling focus |
| 37–41s | Web and Windows artifacts; three delivery receipts | One release. Every destination. |
| 41–45s | Pipelab end card | Static hold for at least 2 seconds |

The complete choreography, layout anchors, and muted-playback test are in [MOTION-STORYBOARD.md](MOTION-STORYBOARD.md).

# Plan: Fix Invalid Characters in Electron Forge Product Name

The `productName` generated by `getProductName` includes a space ("Pipelab Beta"), which is being rejected by Electron Forge during the packaging process.

## Changes

### 1. Update `packages/constants/src/index.ts`
Modify the `getProductName` function to return "Pipelab-Beta" (replacing the space with a hyphen) for beta versions.

```typescript
export const getProductName = (version: string) =>
  version.includes("beta") ? "Pipelab-Beta" : "Pipelab";
```

## Verification

1.  Run `pnpm build` in the root of the project to ensure the constants package is rebuilt.
2.  Navigate to `apps/desktop`.
3.  Attempt to run `pnpm package` to verify that the error regarding invalid characters is resolved.
4.  Confirm that the output package name adheres to the new naming convention.

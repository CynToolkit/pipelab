# Build and ship with Pipelab

Pipelab helps you prepare project builds and move them through repeatable
workflows. The desktop app includes a graph editor for pipelines and a separate
Release workflow editor for selecting a source, build targets, and destinations.

Pipelab has two execution paths with different concepts. [Pipelines](/guide/pipelines)
run plugin actions in graph order. [Release workflows](/guide/release-workflows)
plan build artifacts and send them to destinations. The guides keep those paths
separate so you can follow the one that fits your task.
